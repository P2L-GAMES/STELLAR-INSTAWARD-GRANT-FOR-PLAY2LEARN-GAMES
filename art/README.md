# Source Art

Artwork carried over from the original Unity implementation of this project.
**None of it is used by the current build** — the lobby and in-game cards use
`src/assets/cover1.png` and `src/assets/quiz-chain-card.png`.

It is kept here so the source designs are not lost when the Unity project was
replaced by the Three.js / TypeScript stack.

| File | Size | Dimensions | Intended use |
|---|---|---|---|
| `menu-background.png` | 4.8 MB | 5880 × 2940 | Menu / arena backdrop. Large — worth compressing before any production use. |
| `cover-2.png` | 515 KB | 466 × 666 | Alternative card cover (variant 2) |
| `guess-the-symbol-back.png` | 317 KB | 483 × 691 | Card back for the **Symbol** game mode, which is not implemented yet |

`cover1.png` and `quiz-chain-card.png` were carried into `src/assets/` and are
not duplicated here.
